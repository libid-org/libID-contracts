# libid-identity

The off-chain half of libid handle normalization.

`normalize(raw, rules)` turns a platform handle into the one form the identity
system hashes into a node, mirroring `contracts/identity/HandleNormalizer.sol`
byte for byte: a closed ASCII byte transform — trim spaces, strip one leading
`@` where the platform says so, fold `A-Z`, refuse everything outside the
platform's set. It is deliberately not Unicode case folding and not UTS-46.

The per-platform rules (`Rules::X`, `Rules::GITHUB`, `Rules::GOOGLE`) and the
shared vector table come from `contracts/identity/handles.json`, generated by
`scripts/regen-identity-handles.py`. Solidity, Rust and TypeScript each run
the same table, so a normalizer that drifted from the chain fails a test
instead of looking up a node the chain never wrote.

`handle_vectors` also carries each platform key (`PLATFORM_X_KEY`, …), and
`rules_for` returns a platform's rules by its key; `keccak256` of the key is
the platform id the contracts store under.

No dependencies, on purpose: every consumer of the identity system needs this
transform, and none of them should inherit anything for it.
